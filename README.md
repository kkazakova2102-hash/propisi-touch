# Мастерская письма

Неофициальный сенсорный прототип для сопровождения занятий с опорой на методику В. А. Илюхиной. Не является электронным изданием авторских прописей или сертифицированным продуктом ФГОС.

## Возможности

- Рабочая строка, верхняя и нижняя дополнительные строки.
- Условная «мнимая» линия расположена в верхней дополнительной строке, а не посередине рабочей.
- Ввод пальцем, стилусом или мышью через Pointer Events; отдельный режим только для стилуса.
- 33 строчные буквы и 6 графических элементов; заглавных букв пока нет.
- Показ направления, обводка и самостоятельное письмо.
- Локальный анализ траектории: форма, направление, начало, конец, порядок и число штрихов. Это НЕ распознавание произвольного текста.
- Отмена, очистка, полный экран при поддержке браузера.
- Учитель может нарисовать и использовать собственный образец.
- Экспорт/импорт занятия JSON и сохранение изображения PNG.
- Нет регистрации, аналитики, сервера обработки рисунков или скрытого хранения. Все данные вкладки исчезают после обновления без экспорта.

## Включить сайт

В репозитории откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**.

Дождитесь завершения публикации. Используйте адрес, который GitHub покажет в разделе Pages. Подтверждённая опубликованная ссылка в этой версии не заявляется: включение Pages выполняет владелец.

Сборка не нужна: `index.html` открывает `propisi-touch.html`. Альтернатива — открыть `propisi-touch.html` из скачанного проекта в браузере.

## Методические ограничения

Учебные схемы — самостоятельные геометрические приближения, не точное воспроизведение начертаний и алгоритмов из пособия Илюхиной. Перед работой с детьми педагог должен проверить их и при необходимости заменить своим законно используемым образцом через кнопку «Учителю».

Технический успех означает сходство с выбранной схемой, а не доказательство правильного почерка. Допустимые варианты начертания и отрывов определяет педагог. Занятие на экране дополняет, но не заменяет письмо ручкой в тетради. 3-минутное напоминание об отдыхе — настройка, не утверждение санитарной нормы.

## Проверки

См. `TESTS.md`: 32 автоматизированные проверки в Chromium, в том числе сенсорные события через эмуляцию телефона. На физическом телефоне и активном стилусе приложение ещё не проверялось.

Проверка JavaScript: ESLint (`no-undef`, `no-unreachable`, `no-dupe-keys`, `valid-typeof`), `node --check`.

## Данные и сеть

Рисунки обрабатываются только в браузере. Хостинг GitHub и внешний запрос Google Fonts могут обрабатывать обычные сетевые данные посетителя. Без сети используется системный шрифт. Файл JSON не содержит имён учеников; не дописывайте в него персональные сведения, если собираетесь публиковать его.
